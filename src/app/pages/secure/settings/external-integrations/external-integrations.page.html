External API integrations

Admin-managed connections to external APIs, grouped by category — eKYC verifications run through the default 'ekyc' integration (requests can override per call). Parameters are flexible key/value pairs, encrypted in this dashboard's database — never stored in configuration files — and included in the on-chain settings backup, so they survive a database rebuild. Editing a parameter replaces it; leaving it empty keeps the stored value. Integrations can be linked to service providers (type-2 services) so their usage by entity services is traceable.
